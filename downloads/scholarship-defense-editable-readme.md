# 国家奖学金答辩：可编辑版使用说明

本文件由 image-to-editable-ppt skill 根据原有 10 页 PPT 重建，内容仍分为个人介绍、成果介绍、目前工作。填写区保持空白，原演讲者备注保留。

## 填写与修改

- 标题、栏目文字可以直接点击修改；边框、色带和简单图形可以移动或调整颜色。
- 第 4 页成果总览、第 9 页工作计划使用原生 PowerPoint 表格，直接点击空白单元格填写。
- 其他空白区域可以插入文本框。建议使用微软雅黑或思源黑体，22–26 磅，深蓝色或深灰色，每块填写 1–3 行。
- 第 2 页右侧可放个人照片，第 5 页右侧可放真实结果图，第 6 页左侧可放真实实验或系统图片。
- 封面和结束页的淡蓝装饰保留为背景图片，页面文字及填写表单独立可编辑。
- 在“视图 → 备注”或演示者视图中查看讲稿，将方括号内信息替换为自己的真实内容。
